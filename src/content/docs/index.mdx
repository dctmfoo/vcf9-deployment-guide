## About This Guide

This guide was created to support **VMware Cloud Foundation 9.0 deployment projects** within existing VMware environments. It covers the complete lifecycle from assessment through operational handoff, specifically addressing the significant changes introduced in VCF 9.0.

:::note[Migration Context]
If you're migrating from **VCF 4.5**, be aware that direct upgrade to 9.0 is not supported. The required path is **4.5 → 5.2 → 9.0**. This guide addresses the nuances of this migration, including deprecated components and functionality shifts.
:::

## Project Scope Coverage

This documentation supports the following deployment phases:

<Steps>
1. **Assessment & Planning**
   
   Review existing vSphere, vSAN, and NSX infrastructure for VCF 9 readiness. Validate hardware compatibility, network configuration, and licensing requirements.

2. **Environment Preparation**
   
   Prepare ESXi hosts (firmware, BIOS, networking, vSAN). Configure prerequisite VLANs, IP schemas, DNS, and NTP services.

3. **VCF 9 Deployment**
   
   Deploy the Management Domain using VCF Installer. Configure vCenter, SDDC Manager, and vSAN with post-deployment validation.

4. **Integration & Configuration**
   
   Integrate identity sources, backup solutions, and monitoring. Configure lifecycle management and implement RBAC security best practices.

5. **Knowledge Transfer**
   
   Operational handoff documentation covering the critical SDDC Manager → VCF Operations transition.
</Steps>

## Critical Changes in VCF 9.0

| Component | What Changed | Impact |
|-----------|--------------|--------|
| **SDDC Manager** | UI deprecated | Use VCF Operations console for day-2 operations |
| **Cloud Builder** | Replaced | VCF Installer appliance with JSON/wizard-based deployment |
| **VCF Operations** | Now mandatory | Replaces Aria Operations, handles lifecycle management |
| **VCF Automation** | Now mandatory | Replaces Aria Automation |
| **Identity** | vIDM replaced | VCF Identity Broker for unified SSO |
| **Versioning** | Unified | All components at 9.x (vSphere, NSX, vSAN, SDDC Manager) |
